# 🎵 AUDIO PLAYER — Музыкальный плеер

**Audio Player** — это простой и удобный музыкальный плеер, позволяющий воспроизводить треки по очереди, перелистывать их кнопками и управлять воспроизведением через интерфейс. Каждый трек сопровождается уникальным фоновым изображением. Проект реализован на чистом **HTML**, **CSS (SCSS)** и **JavaScript** без использования сторонних библиотек и фреймворков.

---

## 🎮 Основной функционал

- **Кнопка Play/Pause** — запуск и остановка воспроизведения с изменением иконки.
- **Переключение треков**:
    - Кнопки «Вперёд» и «Назад» перелистывают треки по кругу.
- **Смена изображения** — при смене трека меняется обложка.
- **Прогресс-бар**:
    - Отображает текущее положение трека.
    - Позволяет перематывать трек вручную.
- **Отображение времени**:
    - Общее время трека.
    - Текущее время воспроизведения.
- **Футер** с:
    - Ссылкой на GitHub автора.
    - Логотипом курса Rolling Scopes.
    - Годом создания приложения.
- **Дополнительно**:
    - Поддержка адаптивного интерфейса.
    - Высокое качество оформления.
